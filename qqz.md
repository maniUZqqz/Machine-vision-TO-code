# Quick start (corrected for v2)

> The old version of this file claimed "91.4% / 95.5% pixel similarity". Those numbers were produced by a metric in which
> a pixel counts as equal when it is within 30 grey levels - a blank page in the background colour scores ~88% on it.
> They are **withdrawn**. Honest, reproducible numbers are in [README.md](README.md) / [README.fa.md](README.fa.md)
> (generated by `python -m bench run`).

## Copy & paste

```bash
git clone https://github.com/maniUZqqz/Machine-vision-TO-code.git
cd Machine-vision-TO-code
sudo apt install tesseract-ocr tesseract-ocr-fas tesseract-ocr-eng        # Linux; Windows: UB-Mannheim build + fas/eng data
pip install -e ".[ocr-tesseract,browser,web]"
python -m playwright install chromium     # blocked network? set MV2CODE_CHROME=/path/to/an/existing/chromium instead

# convert a screenshot (responsive flex/table HTML + tree.json + honest scores)
mv2code test_samples/input/1524.png -o out --mode responsive --score

# the honest benchmark (24 generated pages + the 2 real samples; --full = 80 pages)
python -m bench run --quick

# the web app: upload -> original / generated side by side -> ZIP
python manage.py migrate
python manage.py runserver            # http://localhost:8000/
```

Output folder: `index.html`, `fonts/`, `tree.json`, `report.json`, `original.png`. Open `index.html` in a browser.

## More

* Modes: `--mode responsive` (default, editable) or `--mode exact` (pixel-faithful, absolute) or `both`.
* Language: `--lang auto|fa|en`; OCR: `--ocr auto|tesseract|easyocr|none`; retina screenshots: `--dpr 2`.
* Python: `from mv2code import convert` - see the README.
* REST: `curl -F image=@shot.png -F mode=responsive http://localhost:8000/api/convert/`.
* YOLO is optional and never needed: [docs/yolo.md](docs/yolo.md).
* The v1 engine (EasyOCR + absolute layout) is still in the repository (`vision_engine/`, `code_generator/`, `python test_images.py`);
  `MV2CODE_ENGINE=legacy` makes the web app use it. It needs `pip install easyocr` (torch).
